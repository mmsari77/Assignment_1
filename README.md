# Assignment 1

This project contains solutions to 10 programming tasks implemented in Java.

## Overview
- The project is organized into 10 packages: `Task1`, `Task2`, ..., `Task10`.
- Each package contains:
  - `Main.java`: Entry point to run the task.
  - `TaskX.java`: Logic for the task.
  - `TaskXTest.java`: Unit tests for the task.

## How to Build and Run
1. Clone the repository: git clone https://github.com/mmsari77/Assignment_1
2. Open the project in IntelliJ IDEA.
3. Build the project using JDK 17 or higher.

## Tasks
- **Task 1**: Finds the minimum element in an array using an iterative approach, per Problem 1 requirements. Time complexity: O(n).
- **Task 2**: Calculates the average of array numbers using an iterative approach. Time complexity: O(n).
- **Task 3**: Checks if a number is prime using an iterative approach. Time complexity: O(√n).
- **Task 4**: Calculates the factorial of a number using recursion. Time complexity: O(n).
- **Task 5**: Calculates the nth Fibonacci number using recursion. Time complexity: O(2^n).
- **Task 6**: Calculates a raised to the power of n using recursion. Time complexity: O(n).
- **Task 7**: Reverses an array in place using recursion. Time complexity: O(n).
- **Task 8**: Checks if a string consists only of digits using recursion. Time complexity: O(n).
