# Assignment 1

This project contains solutions to 10 programming tasks implemented in Java.

## Overview
- The project is organized into 10 packages: `Task1`, `Task2`, ..., `Task10`.
- Each package contains:
    - `Main.java`: Entry point to run the task.
    - `TaskX.java`: Logic for the task.
    - `TaskXTest.java`: Unit tests for the task.

## How to Build and Run
1. Clone the repository: git clone https://github.com/mmsari77/Assignment_1
2. Open the project in IntelliJ IDEA.
3. Build the project using JDK 17 or higher.
